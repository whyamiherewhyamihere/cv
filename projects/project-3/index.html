Portfold Landing

Современный адаптивный лендинг для сервиса управления инвестициями, разрабатываемый на React

Описание

Современный адаптивный лендинг для сервиса управления инвестициями. Проект разрабатывается на React с использованием компонентного подхода, CSS Modules и Vite. В настоящее время продолжаю работу над проектом, постепенно расширяя функциональность и совершенствуя пользовательский интерфейс.

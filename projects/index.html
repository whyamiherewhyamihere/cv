  • Quarto — браузерная настольная игра
    Браузерная реализация настольной игры Quarto, разработанная в рамках обучения в Университете ИТМО. Проект создан с использованием PHP, SQL, HTML, CSS и JavaScript. Реализованы игровая логика, хранение данных с использованием базы данных SQL и удобный веб-интерфейс для взаимодействия пользователей.
  • Portfold Landing

  • Cadence Connections — интернет-магазин велосипедных компонентов
    Интернет-магазин велосипедных компонентов, разработанный в качестве выпускной квалификационной работы при окончании бакалавриата Университета ИТМО. Проект включает каталог товаров, систему категорий, страницы товаров и адаптивный пользовательский интерфейс.
